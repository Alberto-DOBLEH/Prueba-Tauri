# SumatraPDF Portable

Coloca aqui el binario portable de SumatraPDF para que Tauri lo empaquete dentro del instalador.

Archivo recomendado:

```text
SumatraPDF.exe
```

Tambien se aceptan binarios versionados oficiales con nombre tipo:

```text
SumatraPDF-3.6.1-64.exe
```

Ruta esperada en este proyecto:

```text
Frontend/src-tauri/resources/sumatrapdf/SumatraPDF.exe
```

Usar el binario portable oficial, no el instalador. Si se distribuye dentro del instalador de POS Local, conservar tambien la licencia correspondiente de SumatraPDF/GPLv3.
